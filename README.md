# সাথী AI ✨

বাংলায় কথা বলা একটা AI সহকারী অ্যাপ (Android)। ফ্রি Google Gemini API দিয়ে চলে।

## যা পারে
- যেকোনো প্রশ্নের উত্তর, লেখা, অনুবাদ, শেখানো
- ছবি ও PDF বুঝে উত্তর
- বাংলায় ভয়েসে বলা, উত্তর পড়ে শোনানো
- ইন্টারনেট সার্চ (খবর, দাম, রেট), সূত্রসহ
- নির্ভুল হিসাব, কোড লেখা
- ফোনের স্টোরেজ বিশ্লেষণ, ফাইল দেখা ও সেভ করা
- সব চ্যাট সেভ থাকে

## বিল্ড
কোড বদলালে GitHub Actions নিজেই APK বানায় (Releases-এ `build-N`)।
সেগুলো unsigned, সরাসরি ইনস্টল হয় না। ইনস্টলযোগ্য, সাইন করা APK আলাদাভাবে দেওয়া হয়।
সিগনেচার কী এই public রিপোজিটরিতে রাখা হয়নি।

## প্রথমবার চালু
মেনু (☰) → সেটিংস → ফ্রি Gemini API key দিন (aistudio.google.com)।
