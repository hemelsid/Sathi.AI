# সাথী AI ✨

বাংলায় কথা বলা একটা AI সহকারী অ্যাপ (Android)। ফ্রি Google Gemini API দিয়ে চলে।

## যা পারে (v2)
- **স্মার্ট চ্যাট:** লাইভ টাইপিং, মার্কডাউন, টেবিল, কোড, এডিট ও আবার উত্তর, চ্যাট খোঁজা/পিন/শেয়ার
- **এজেন্ট মোড:** ধাপে ধাপে কাজ — ওয়েব সার্চ, পেজ পড়া, হিসাব, কোড চালানো, আবহাওয়া, মুদ্রা, উইকিপিডিয়া, ছবি আঁকা, অ্যালার্ম/টাইমার/ক্যালেন্ডার, কল/SMS/ইমেইল খোলা, ফাইল সেভ, স্টোরেজ বিশ্লেষণ
- **অনেক AI একসাথে:** ফ্রি — Gemini, Groq, OpenRouter, Mistral, Cerebras, GitHub Models, Pollinations; পেইড — OpenAI, Claude, DeepSeek, Grok, Together; নিজের সার্ভার — Ollama/LM Studio, যেকোনো OpenAI-compatible
- **সাথী অটো:** সেরা চালু মডেল নিজে বেছে নেয়, সমস্যা হলে অন্যটায় যায়
- **আমার মডেল:** নিজের AI বানান — নাম, ব্যক্তিত্ব, নির্দেশনা, নিজের জ্ঞান
- **স্মৃতি:** আপনার সম্পর্কে মনে রাখে
- **ভয়েস:** AI দিয়ে নির্ভুল বাংলা ভয়েস চেনা (Whisper/Gemini), স্বাভাবিক AI কণ্ঠ, হাত-ছাড়া কথোপকথন মোড
- ছবি/PDF/অডিও বোঝে, ডার্ক/লাইট থিম

## বিল্ড
কোড বদলালে GitHub Actions নিজেই APK বানায় (Releases-এ `build-N`)।
সেগুলো unsigned, সরাসরি ইনস্টল হয় না। ইনস্টলযোগ্য, সাইন করা APK আলাদাভাবে দেওয়া হয়।
সিগনেচার কী এই public রিপোজিটরিতে রাখা হয়নি।
